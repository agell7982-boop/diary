## 1. 프로젝트 개요

"나만의 다이어리"는 웹 브라우저(PWA)와 안드로이드 스마트폰 네이티브 앱(Capacitor APK) 환경을 모두 완벽하게 지원하는 감성 일정 관리 & 보안 일기장 하이브리드 애플리케이션입니다.

- **핵심 기능**:
  1. **일정 관리**: 주간/일별 일정 등록, 시간별 정렬, 알람 설정, 완료 체크, 삭제 및 되돌리기(Undo).
  2. **한 달 달력**: 음력/양력 대한민국 공휴일 및 대체공휴일 자동 계산, 실시간 날씨 연동(Open-Meteo), 월간 목표(CRUD), 반복 일정(요일별/N일마다).
  3. **기록(일기장)**: SHA-256 단방향 암호화 잠금, 하루 일기 작성, 캔버스 기반 사진 초경량 압축 첨부.
  4. **스마트 알람 & 사운드**: 화면 꺼짐 시에도 100% 울리는 안드로이드 시스템 알람(`LocalNotifications`), 고음질 알람벨(`alarm_bell.wav`), 내 음악(MP3) 첨부 및 재생, 실시간 음량 조절, 백그라운드 절전 방지(Keep-Alive).
  5. **하루 일정 조절 알림 (신규)**: 매일 지정한 시간(기본 08:30)에 오늘 계획을 점검하라는 푸시 알림 및 모달 팝업, [오늘 일정 보러가기] 원클릭 이동.
  6. **클라우드 실시간 동기화**: Firebase Firestore & Auth 연동, 계정 간 데이터 자동 백업 및 복원.

## 3. 핵심 문제 해결 히스토리 (Troubleshooting)

### ① 구글 간편 로그인 시 ChatGPT로 튕기던 문제
- **원인**: 안드로이드 웹뷰(APK) 환경에서는 브라우저 팝업(`signInWithPopup`)이 차단되어 `signInWithRedirect`로 넘어가는데, 안드로이드 OS가 외부 웹 링크를 기기의 기본 어시스턴트(ChatGPT)로 넘겨버림.
- **해결**: 모바일 환경(`isNativeApp()`)을 자동 감지하여 모바일에서는 외부 튕김이 일체 없는 **앱 전용 직접 이메일/비밀번호 로그인 및 회원가입 폼**을 표시하도록 개편. 비밀번호 재설정 메일 발송 기능도 추가.

### ② 백그라운드에서 알림 메시지만 뜨고 소리가 안 나던 문제
- **원인**: 안드로이드 8.0 이상에서 NotificationChannel의 중요도(`Importance`)가 낮거나 사운드가 지정되지 않은 기본 채널로 알림이 발송되어 시스템이 백그라운드 소리를 묵음 처리함.
- **해결**: 고음질 알람벨(`alarm_bell.wav`)을 네이티브 리소스(`res/raw/alarm_bell.wav`)에 배치하고, 최고 중요도(`importance: 5`, `IMPORTANCE_HIGH`, `vibration: true`, `sound: 'alarm_bell.wav'`)를 갖는 전용 채널(`diary_loud_alarm_v3`)을 생성하여 화면 꺼짐 상태에서도 소리와 진동이 100% 울리도록 조치.

### ③ 첨부한 노래(MP3)가 앱 재시작 후 기계음으로 바뀌던 문제
- **원인**: 음원 첨부 시 임시 상태만 변경되고 즉시 저장되지 않아 앱 종료 시 기본음으로 리셋되었으며, Web Audio API `decodeAudioData`로 긴 MP3를 디코딩할 때 웹뷰 메모리 부족으로 디코딩 실패가 발생하여 기계음으로 폴백됨.
- **해결**: 음원 첨부 즉시 `S.cfg.alarmSound = 'custom'`으로 영구 저장하고, Base64 Data URL을 스마트폰 하드웨어 엔진인 HTML5 `new Audio(...)`로 스트리밍 재생하도록 개선하여 앱을 껐다 켜도 등록한 노래가 영구히 재생됨.

### ④ 하루 일정 조절 알림 (데일리 루틴 알림) 신규 추가
- **내용**: [설정] 탭에 전용 카드를 신설하여 매일 정해진 시간(기본 08:30)에 사용자가 입력한 메시지로 알람이 울리고, [오늘 일정 보러가기 📝] 버튼을 누르면 즉시 [일정] 화면으로 이동하는 기능 구현 완료.

### ⑤ 설정 화면 아코디언(접기/펼치기) 개편 및 백그라운드 알람 통합
- **아코디언 UI 개편**: 길게 펼쳐져 복잡했던 설정 섹션들을 탭 터치 시 부드럽게 펼쳐지는 아코디언 카드 구조로 개편. 접혀 있을 때도 각 카드의 기능 요약 설명과 현재 적용된 상태 배지(계정 상태, 테마, 알람음/음량, 루틴 시간 등)가 한눈에 보이도록 직관화.
- **알람 설정 통합**: 중복되던 '푸시 알림 권한'과 '화면 꺼짐 시 알람 유지'를 **[화면 꺼짐 및 백그라운드 알람 유지]** 단일 스위치로 완전 통합.
- **"이 브라우저는 알림을 지원하지 않아요" 해결**: 모바일 APK 환경에서 웹 `window.Notification`만 검사하여 지원 불가 오류가 발생하던 문제를 해결. 안드로이드 환경(`isNativeApp()`)을 자동 감지하여 시스템 `LocalNotifications` 권한을 요청/연동하고, 5초 뒤 백그라운드 테스트도 실제 네이티브 시스템 알람으로 발송. 알림 미지원 웹 환경에서는 무의미한 권한 요청 대신 안내 문구 및 전용 APK 링크로 대체.

### ⑥ 직접 시간 입력 지원(시계 팝업 제거) 및 원클릭 자동 업데이트 기능 추가
- **직접 시간 입력 지원**: 하루 일정 조절 알림에서 불필요하게 뜨던 모바일 시계 다이얼로그(타임 피커)를 제거하고, 키보드로 원하는 시간(예: `08:30`, `8:30`, `14:00`)을 직접 적어서 직관적으로 설정할 수 있도록 개선 (유연한 자동 시간 정규화 지원).
- **자동 업데이트 시스템 (`version.json`)**:
  - 설정 상단 및 [계정 & 백업] 카드에 앱 버전 관리(`v2.3.0`) 및 실시간 업데이트 감지 로직 탑재.
  - 새 버전이 배포되면 설정 상단과 [계정 & 백업]에 눈에 띄는 **[🚀 새 버전 업데이트]** 배너 및 버튼이 자동으로 활성화됨.
  - 버튼 원클릭으로 웹(PWA)은 서비스워커 캐시 자동 클리어 및 즉시 새로고침 반영, 모바일 앱(APK)은 원클릭 최신 설치 파일 다운로드로 연결.

### ⑦ 일정 시간 직접 쓰기(`:`) 및 상하 드래그 휠 피커, 안드로이드 뒤로가기 앱 튕김 방지, 일기 저장 및 지난 일기 모아보기
- **일정(+) 시간 설정 혁신**:
  - 기존 5분 단위 드롭다운을 제거하고, 상단에 `[시] : [분]` 직접 입력창과 하단에 손으로 부드럽게 위아래로 굴리는 **스크롤/드래그 휠 피커(Wheel Picker, 1분 단위 모든 분 지원)** 탑재.
  - 직접 키보드로 적어도 휠이 자동으로 굴러가 맞추어지고, 휠을 손으로 굴려도 상단 직접 입력창의 숫자가 실시간으로 연동되는 **양방향 실시간 동기화** 완성. 종일 일정 버튼도 바로 옆에 지원.
- **뒤로가기(Back Button) 앱 종료 방지**:
  - 모달이나 시트(일정 추가, 반복 일정, 달력 상세 보기 등)가 열려 있을 때 스마트폰 뒤로가기 버튼이나 제스처를 누르면 앱 밖으로 튕기던 문제를 해결.
  - 최상위 열린 창을 감지하여 안전하게 닫고 이전 화면으로 복귀하도록 개선 (`Capacitor.Plugins.App` 및 `popstate` 연동). 메인 화면에서만 2초 내 재터치 시 앱 종료 알림.
- **기록(일기장) 저장 버튼 및 지난 일기 모아보기**:
  - 일기 작성란에 명확한 **`[💾 일기 저장 / 확인]`** 버튼을 추가하여 터치 시 즉시 저장 및 안내 토스트 제공.
  - 하단에 **`[📖 지난 일기 모아보기 (N편)]`** 카드 목록을 신설하여, 지금까지 작성한 모든 일기들을 최신순으로 한눈에 보고 터치하여 바로 열람/수정 및 삭제 가능.

### ⑧ v2.4.0 대규모 사용성 혁신 (사진 3~5장 다중 첨부 & 확대 뷰어, 일기 읽기/수정 모드 분리, 달력 일기 기호 표시, 뒤로가기 내비게이션 완성, 업데이트 버튼 단일 통합)
- **설정 업데이트 UI 단일 통합**:
  - 기존의 수평 나열 2개 버튼(`[업데이트 확인]`, `[최신 APK 받기 📥]`)을 제거하고 깔끔한 단일 버튼(`[버전 확인 & 업데이트]`)으로 통합.
  - 버튼 터치 시 최신 버전을 실시간 조회하여 상세 팝업 모달을 띄우고, 모달 내부에서 원클릭으로 최신 APK 다운로드까지 완벽하게 처리.
- **사진 3~5장 다중 첨부 & 크기 제한 & 확대 라이트박스**:
  - 갤러리 다중 선택(`multiple`) 지원으로 한 번에 여러 장의 사진을 묶어서 선택 가능.
  - 하루 일기당 최대 5장 제한 및 15MB 개별 파일 크기 검증, 800px & JPEG 0.65 캔버스 압축으로 5장을 모두 올려도 400KB 수준의 초경량 유지.
  - 첨부 사진 터치 시 전체화면 확대 라이트박스(`photo-lightbox`)를 띄워 선명하게 감상 가능 (닫기 버튼, 배경 터치, 뒤로가기로 닫기 지원).
- **일기 목록 제목 간소화 & [읽기 모드] vs [수정 모드] 분리**:
  - 지난 일기 목록에서 본문/사진 미리보기를 제외하고 `[날짜]`와 `[일기 제목]`만 한 줄씩 단정하게 표시하는 콤팩트 리스트로 전환.
  - 일기가 작성된 날짜를 선택하면 실수로 글을 지울 염려가 없는 안전하고 미려한 **읽기 전용 뷰**로 표시.
  - 하단의 **`[✏️ 일기 수정하기]`** 버튼을 눌렀을 때만 작성/수정 폼(입력창, 사진 추가, 저장)이 열리도록 완벽히 분리.
- **달력 및 일정 목록에 일기 작성(📝) 기호/배지 표시**:
  - 월간 달력 및 주간 달력의 날짜 셀에 일기가 작성된 날은 작고 귀여운 `📝` 아이콘을 표시.
  - 날짜 상세 패널 및 일정 탭 상단 헤더에 `[📝 일기 작성됨 ›]` 배지를 노출하여 터치 시 해당 일기 읽기 모드로 즉시 점프.
- **계층형 뒤로 가기(Back) 내비게이션 완성**:
  - 사진 확대 라이트박스 ➔ 업데이트 모달 ➔ 알람 다이얼로그 ➔ 일정/반복 시트 ➔ 일기 수정 취소 ➔ 탭 히스토리 스택(`TAB_STACK`) 복귀 ➔ 메인 첫 화면(일정 탭)에서 2회 연속 터치 시 앱 종료 안내의 계층형 스택 완성.
  - PWA 및 안드로이드 웹뷰 모두에서 앱 밖으로 튕기지 않고 화면 단계별로 안전하게 복귀되도록 보호.

### ⑨ v2.4.1 긴급 핫픽스 (업데이트 모달 터치 먹통 해결, 자동 팝업 방지, 실시간 날씨 초고속 연동)
- **업데이트 모달 터치 먹통 해결**:
  - 기존 `#app`에만 걸려 있던 클릭 이벤트 리스너로 인해 `document.body`에 생성된 `#update-modal`의 클릭(`data-a`)이 전달되지 않아 버튼이 완전히 먹통이 되던 문제를 해결.
  - 전역 `document.addEventListener('click')` 위임 및 모달 내부 버튼에 직접 `.onclick` 핸들러 바인딩, 모달 바깥 어두운 배경 터치 시 닫기 지원.
- **백그라운드 자동 체크 시 강제 전체화면 모달 팝업 방지**:
  - 앱 시작 시 백그라운드에서 새 버전을 감지했을 때 화면 전체를 덮는 강제 팝업 모달을 띄우지 않고, 상단 배너와 카드 배지만 깔끔하게 활성화되도록 변경.
  - 사용자가 배너의 `[지금 자동 업데이트]` 또는 카드의 `[버전 확인 & 업데이트]`를 직접 눌렀을 때만 모달이 뜨도록 UX 개선.
- **실시간 날씨 초고속 연동 (`wttr.in` & 로컬 캐싱)**:
  - 타임아웃 및 접속 지연이 발생하던 기존 `api.open-meteo.com` 대신 국내외에서 초고속 응답하는 `wttr.in/Seoul?format=j1` 엔진을 1순위로 도입.
  - 실시간 날씨 아이콘(☀️, 🌤️, ☁️, 🌧️, 🌨️ 등)과 최고/최저 기온을 즉시 가져오고, 로컬 캐시(`localStorage`)에도 저장하여 오프라인이거나 느린 환경에서도 날씨가 즉시 표시되도록 개선.
