## 1. 프로젝트 개요

**"나만의 다이어리"**는 웹 브라우저(PWA)와 안드로이드 스마트폰 네이티브 앱(Capacitor APK) 환경을 모두 완벽하게 지원하는 감성 일정 관리, 스마트 알람, 날씨 연동 및 비밀번호 보안 일기장 하이브리드 애플리케이션입니다.

### 🌟 핵심 기능 요약
1. **일정 관리**: 주간/일별 일정 등록, 시:분 직접 입력(`:`) 및 부드러운 상하 드래그 휠 피커, 시간순 자동 정렬, 알람 설정, 완료 체크, 삭제 및 되돌리기(Undo).
2. **한 달 달력**: 음력/양력 대한민국 공휴일 및 대체공휴일 자동 계산, 실시간 날씨 연동(wttr.in & Open-Meteo), 월간 목표(CRUD), 반복 일정(요일별/N일마다).
3. **기록(일기장)**:
   - **타인 열람 방지 비밀번호 잠금**: SHA-256 단방향 암호화 잠금, 일기 작성 후 `[🔒 일기장 지금 잠그기]`.
   - **비밀번호 분실 안심 대책**: 비밀번호 분실 시 데이터 유실 없이 안전하게 초기화/재설정 지원.
   - **날씨 영구 저장 & 선택기**: 5가지 날씨(`☀️, 🌤️, ☁️, 🌧️, 🌨️`) 선택 및 지난 일기 날씨 영구 보존.
   - **사진 다중 첨부 (최대 5장)**: 15MB 용량 검증 및 초경량 캔버스 압축, 전체화면 라이트박스 확대 감상, 손가락 좌우 스와이프 제스처 넘기기 지원.
   - **읽기 모드 vs 수정 모드 분리**: 실수로 일기를 지우지 않는 깔끔한 읽기 전용 뷰와 콤팩트 지난 일기 목록.
4. **스마트 알람 & 사운드**: 화면 꺼짐 시에도 100% 울리는 안드로이드 시스템 알람(`LocalNotifications`), 고음질 알람벨(`alarm_bell.wav`), 내 음악(MP3) 첨부 및 영구 재생, 실시간 음량 조절, 백그라운드 절전 방지(Keep-Alive).
5. **하루 일정 조절 알림 (데일리 루틴)**: 매일 지정한 시간(직접 시간 입력 지원, 기본 08:30)에 오늘 계획을 점검하라는 푸시 알림 및 모달 팝업, [오늘 일정 보러가기] 원클릭 이동.
6. **클라우드 실시간 동기화 & 백업**: Firebase Firestore & Auth 연동, 모바일 전용 직접 로그인/회원가입 지원, Google Drive 백업 및 로컬 파일 백업(.json).
7. **안전한 원클릭 자동 업데이트**: 외부 브라우저(크롬/삼성 인터넷) 안전 연동으로 앱 멈춤 없이 백그라운드 다운로드 진행.

## 3. 상세 개선 및 문제 해결 히스토리 (Chronological Troubleshooting)

### ① 구글 간편 로그인 시 ChatGPT로 튕기던 문제
- **원인**: 안드로이드 웹뷰(APK) 환경에서는 브라우저 팝업(`signInWithPopup`)이 차단되어 `signInWithRedirect`로 넘어가는데, 안드로이드 OS가 외부 웹 링크를 기기의 기본 어시스턴트(ChatGPT)로 넘겨버림.
- **해결**: 모바일 환경(`isNativeApp()`)을 자동 감지하여 모바일에서는 외부 튕김이 일체 없는 **앱 전용 직접 이메일/비밀번호 로그인 및 회원가입 폼**을 표시하도록 개편. 비밀번호 재설정 메일 발송 기능도 추가.

### ② 백그라운드에서 알림 메시지만 뜨고 소리가 안 나던 문제
- **원인**: 안드로이드 8.0 이상에서 NotificationChannel의 중요도(`Importance`)가 낮거나 사운드가 지정되지 않은 기본 채널로 알림이 발송되어 시스템이 백그라운드 소리를 묵음 처리함.
- **해결**: 고음질 알람벨(`alarm_bell.wav`)을 네이티브 리소스(`res/raw/alarm_bell.wav`)에 배치하고, 최고 중요도(`importance: 5`, `IMPORTANCE_HIGH`, `vibration: true`, `sound: 'alarm_bell.wav'`)를 갖는 전용 채널(`diary_loud_alarm_v3`)을 생성하여 화면 꺼짐 상태에서도 소리와 진동이 100% 울리도록 조치.

### ③ 첨부한 노래(MP3)가 앱 재시작 후 기계음으로 바뀌던 문제
- **원인**: 음원 첨부 시 임시 상태만 변경되고 즉시 저장되지 않아 앱 종료 시 기본음으로 리셋되었으며, Web Audio API `decodeAudioData`로 긴 MP3를 디코딩할 때 웹뷰 메모리 부족으로 디코딩 실패가 발생하여 기계음으로 폴백됨.
- **해결**: 음원 첨부 즉시 `S.cfg.alarmSound = 'custom'`으로 영구 저장하고, Base64 Data URL을 스마트폰 하드웨어 엔진인 HTML5 `new Audio(...)`로 스트리밍 재생하도록 개선하여 앱을 껐다 켜도 등록한 노래가 영구히 재생됨.

### ④ 하루 일정 조절 알림 (데일리 루틴 알림) 신규 추가
- **내용**: [설정] 탭에 전용 카드를 신설하여 매일 정해진 시간(기본 08:30)에 사용자가 입력한 메시지로 알람이 울리고, [오늘 일정 보러가기 📝] 버튼을 누르면 즉시 [일정] 화면으로 이동하는 기능 구현 완료.

### ⑤ 설정 화면 아코디언(접기/펼치기) 개편 및 백그라운드 알람 통합
- **아코디언 UI 개편**: 길게 펼쳐져 복잡했던 설정 섹션들을 탭 터치 시 부드럽게 펼쳐지는 아코디언 카드 구조로 개편. 접혀 있을 때도 각 카드의 기능 요약 설명과 현재 적용된 상태 배지(계정 상태, 테마, 알람음/음량, 루틴 시간 등)가 한눈에 보이도록 직관화.
- **알람 설정 통합**: 중복되던 '푸시 알림 권한'과 '화면 꺼짐 시 알람 유지'를 **[화면 꺼짐 및 백그라운드 알람 유지]** 단일 스위치로 완전 통합.
- **"이 브라우저는 알림을 지원하지 않아요" 해결**: 모바일 APK 환경에서 웹 `window.Notification`만 검사하여 지원 불가 오류가 발생하던 문제를 해결. 안드로이드 환경(`isNativeApp()`)을 자동 감지하여 시스템 `LocalNotifications` 권한을 요청/연동하고, 5초 뒤 백그라운드 테스트도 실제 네이티브 시스템 알람으로 발송.

### ⑥ 직접 시간 입력 지원(시계 팝업 제거) 및 원클릭 자동 업데이트 기능 추가
- **직접 시간 입력 지원**: 하루 일정 조절 알림에서 불필요하게 뜨던 모바일 시계 다이얼로그(타임 피커)를 제거하고, 키보드로 원하는 시간(예: `08:30`, `8:30`, `14:00`)을 직접 적어서 직관적으로 설정할 수 있도록 개선.
- **자동 업데이트 시스템 (`version.json`)**: 설정 상단 및 [계정 & 백업] 카드에 앱 버전 관리(`v2.3.0`) 및 실시간 업데이트 감지 로직 탑재.

### ⑦ 일정 시간 직접 쓰기(`:`) 및 상하 드래그 휠 피커, 안드로이드 뒤로가기 앱 튕김 방지, 일기 저장 및 지난 일기 모아보기

- **뒤로가기(Back Button) 앱 종료 방지**: 모달/시트 열림 감지 및 이전 화면 복귀 (`Capacitor.Plugins.App` 및 `popstate` 연동). 메인 화면에서만 2초 내 재터치 시 앱 종료.

- **일정 (+) 추가 시트 입력창 터치 튕김(닫힘) 버그 해결**:
  - 원인: 전역 클릭 위임에서 인풋 클릭 시 상위 오버레이(`.ov[data-a="ovx"]`)가 매칭되어 시트가 즉시 닫힘.
  - 해결: `b.classList.contains('ov') && e.target !== b` 방어 로직으로 시트 내부 터치 시 닫히지 않고 글을 쓸 수 있도록 조치.
- **날씨 영구 저장 및 일기 날씨 연동**:
  - 일기 저장(`A.dysave`) 시 당일 날씨가 `S.diary[sel].weather`에 영구 보존.
  - 일기 작성란 상단에 날씨 선택 바(`☀️, 🌤️, ☁️, 🌧️, 🌨️`) 제공.
  - 일기 읽기 모드 및 지난 일기 목록에서 날짜별 저장 날씨 아이콘/텍스트 노출.

### ⑬ v2.5.1 최신 APK 다운로드 시 외부 브라우저 안전 연동 및 웹뷰 외부 이동/멈춤 버그 완벽 해결
- **"다운로드할까요 문구 후 엉뚱한 화면 올라오고 작동 멈춤" 문제 해결**:
  - 원인: 앱 웹뷰 내부에서 `window.location.href = dlUrl`을 호출하여 다이어리 앱 화면이 깃허브 웹페이지로 덮어씌워져 앱 런타임이 파괴되고 멈춤.
  - 해결:
    1. `@capacitor/browser` 플러그인 탑재 및 `openExternalUrl(url)` 유틸 신설: 안드로이드 기본 브라우저(크롬/삼성 인터넷)로 다운로드 링크를 안전하게 넘김.
    2. 다이어리 앱 화면은 그대로 유지되어 절대 외부 웹페이지로 이동하지 않고 멈춤 원천 차단.
    3. `MainActivity.java`에 네이티브 `setDownloadListener`를 장착하여 시스템 다운로드 매니저와 100% 연동.
    4. 버튼 명칭을 `[지금 APK 다운로드 📥]`로 명확화하고 친절한 진행 안내 토스트 제공.

### ⑭ v2.5.2 기록 비밀번호 잠금 복원 및 분실 시 안전 재설정 지원
- **기록(일기장) 비밀번호 잠금 완전 복원**:
  - 타인이 일기를 보지 못하도록 보호하는 [기록] 탭의 비밀번호 잠금 화면(`lockHTML`), 잠금 상태(`U=false`), 하단 `[🔒 일기장 지금 잠그기]` 버튼 복원.
  - [설정] 탭의 `[🔐 일기 보안 & 비밀번호]` 카드(잠금 켜짐/꺼짐 토글, 비밀번호 등록/변경) 완벽 복원.
- **비밀번호 분실 시 안전 재설정 기능 신설**:
  - 비밀번호를 잊어버렸을 때 일기장이 영구 잠기는 문제를 방지하기 위해 잠금 화면에 `[비밀번호를 분실하셨나요?]` 버튼 추가.
  - 클릭 시 확인 팝업을 거쳐 소중한 일기 데이터 유실 없이 비밀번호만 안전하게 초기화하고, [설정]에서 새 비밀번호를 등록할 수 있도록 구현.

### ⑮ 백그라운드 프로세스(Tasks Running) 누적 원인 및 완전 정리
- **원인**: 통합 테스트 스크립트(`test-full-integration.js`) 내부의 알람 타이머 인터벌로 인해 Node 프로세스가 종료되지 않고 백그라운드에 남아있었음.
- **해결**: 실행 중이던 모든 백그라운드 작업을 즉시 강제 종료(Kill)하여 백그라운드 실행 작업 0개로 정리하고, 테스트 스크립트에 `process.exit(0)`을 추가하여 재발 방지 완료.

## 4. 며칠간 사용하면서 확인해 보실 주요 기능 체크리스트

| 분류 | 기능 항목 | 확인 포인트 |
| :--- | :--- | :--- |
| **일정** | 일정 등록 및 시간 입력 | `+` 버튼을 눌러 시트가 열렸을 때 튕기지 않고 글이 잘 적히는지, 상단 `[시] : [분]` 직접 입력과 하단 휠 피커 드래그가 매끄럽게 동기화되는지 |
| **일정** | 알람 및 사운드 | 지정한 시간에 고음질 알람벨(또는 등록한 내 음악)이 잘 울리는지, 화면 꺼짐 상태에서도 제시간에 소리가 나는지 |
| **일정** | 데일리 루틴 알림 | 매일 설정한 시간(기본 08:30)에 하루 일정 조절 알림이 울리고 버튼 터치 시 일정 화면으로 바로 가는지 |
| **달력** | 날짜 선택 & 공휴일 | 대한민국 공휴일/대체공휴일이 맞게 나오는지, 날짜 선택 시 파스텔 톤 하이라이트가 눈에 편안한지, 일기 쓴 날 `📝` 기호가 잘 표시되는지 |
| **달력** | 월간 목표 & 반복 | 이번 달 목표 추가/완료/삭제가 정상인지, 반복 일정이 주기별로 잘 생성되는지 |
| **기록** | 비밀번호 잠금 & 열람 | 앱 실행 후 기록 탭 진입 시 비밀번호를 입력해야 열리는지, 타인이 볼 수 없게 잘 잠기는지 |
| **기록** | 비밀번호 분실 재설정 | 혹시 비밀번호를 잊었을 때 `[비밀번호를 분실하셨나요?]`를 통해 일기 손실 없이 안전하게 다시 열 수 있는지 |
| **기록** | 날씨 선택 & 영구 저장 | 일기 작성 시 상단 날씨 바(`☀️, 🌤️, ☁️, 🌧️, 🌨️`)로 날씨를 고르고 저장했을 때 지난 일기 목록과 읽기 모드에 날씨가 잘 보존되는지 |
| **기록** | 사진 3~5장 첨부 & 스와이프 | 사진을 여러 장 첨부했을 때 잘 올라가는지, 사진 터치 시 확대 뷰어가 열리고 손가락으로 좌우 쓸어 넘기기(스와이프)가 부드럽게 넘어가는지 |
| **기록** | 읽기 모드 / 수정 모드 | 작성된 일기가 읽기 전용으로 안전하게 보이고, `[✏️ 일기 수정하기]`를 눌러야만 수정 입력창이 뜨는지 |
| **설정** | APK 자동 다운로드 | 설정 상단 또는 [계정 & 백업]의 `[지금 APK 다운로드]` 버튼을 눌렀을 때, 엉뚱한 화면으로 멈추지 않고 스마트폰 브라우저(크롬/삼성인터넷)에서 안전하게 다운로드되는지 |
| **공통** | 스마트폰 뒤로가기 키 | 모달, 시트, 사진 뷰어가 열려있을 때 뒤로가기 버튼을 누르면 앱이 꺼지지 않고 창만 안전하게 닫히는지 |

## 5. 안드로이드 APK 빌드 환경 및 절차

- **JDK 위치**: `E:\Project\diary\.jdk21\jdk-21.0.13+9` (Eclipse Temurin JDK 21 LTS 독립 설치본)
- **빌드 절차**:
  1. `node copy-www.js` (웹 자산을 `www/` 폴더로 동기화)
  2. `npx.cmd cap sync android` (Capacitor 네이티브 프로젝트에 반영)
  3. `android/gradlew.bat assembleDebug` (APK 컴파일)
  4. 컴파일된 APK를 루트의 `diary-debug.apk`로 복사
- **원클릭 빌드**: 프로젝트 루트의 `build-apk.bat` 실행 시 위 과정이 자동 수행됨.
