## 1. 프로젝트 개요

"나만의 다이어리"는 웹 브라우저(PWA)와 안드로이드 스마트폰 네이티브 앱(Capacitor APK) 환경을 모두 완벽하게 지원하는 감성 일정 관리 & 보안 일기장 하이브리드 애플리케이션입니다.

- **핵심 기능**:
  1. **일정 관리**: 주간/일별 일정 등록, 시간별 정렬, 알람 설정, 완료 체크, 삭제 및 되돌리기(Undo).
  2. **한 달 달력**: 음력/양력 대한민국 공휴일 및 대체공휴일 자동 계산, 실시간 날씨 연동(Open-Meteo), 월간 목표(CRUD), 반복 일정(요일별/N일마다).
  3. **기록(일기장)**: SHA-256 단방향 암호화 잠금, 하루 일기 작성, 캔버스 기반 사진 초경량 압축 첨부.
  4. **스마트 알람 & 사운드**: 화면 꺼짐 시에도 100% 울리는 안드로이드 시스템 알람(`LocalNotifications`), 고음질 알람벨(`alarm_bell.wav`), 내 음악(MP3) 첨부 및 재생, 실시간 음량 조절, 백그라운드 절전 방지(Keep-Alive).
  5. **하루 일정 조절 알림 (신규)**: 매일 지정한 시간(기본 08:30)에 오늘 계획을 점검하라는 푸시 알림 및 모달 팝업, [오늘 일정 보러가기] 원클릭 이동.
  6. **클라우드 실시간 동기화**: Firebase Firestore & Auth 연동, 계정 간 데이터 자동 백업 및 복원.

## 2. 파일 및 모듈 아키텍처

기존 단일 `index.html` 파일에 집중되어 있던 수천 줄의 코드를 토큰 절약 및 유지보수 효율을 위해 **9개의 독립 모듈**로 분할하여 순차 로드 구조로 구축했습니다.

```
diary/
├── index.html                   # HTML 진입점 (css 및 js 9개 모듈 순차 로드)
├── manifest.json                # PWA 웹앱 매니페스트
├── sw.js                        # 서비스 워커 (오프라인 캐싱 및 시스템 알람 트리거)
├── favicon.png / icon-*.png     # 앱 아이콘 리소스
├── alarm_bell.wav               # 고음질 시스템 알람 벨소리 리소스
├── diary-debug.apk              # 빌드 완료된 최신 안드로이드 설치 파일 (배포용)
├── copy-www.js                  # 웹 자산을 www/ 폴더로 복사하는 스크립트

├── verify-actions.js            # HTML data-a 액션과 JS 핸들러 일치 검증 도구
├── test-full-integration.js     # 전체 기능 가상 브라우저 통합 테스트 도구
├── css/
│   └── style.css                # 전체 감성 UI 스타일시트 (테마 반응형)
├── js/
│   ├── state.js                 # [1] 전역 상태(S), 로컬스토리지, 공휴일 계산, 날씨, 공통 함수
│   ├── audio.js                 # [2] HTML5 오디오 & Web Audio API 음원 합성 엔진, Keep-Alive

│   ├── today.js                 # [4] [일정] 탭 화면, 주간 달력, 일정 목록, 시간/알람 시트 모달
│   ├── calendar.js              # [5] [달력] 탭 화면, 한 달 달력, 월간 목표, 반복 일정 모달
│   ├── diary.js                 # [6] [기록] 탭 화면, SHA-256 암호 잠금, 일기 작성, 사진 압축
│   ├── settings.js              # [7] [설정] 탭 화면, 테마 색상, 알람 사운드/음량, 데일리 루틴 설정
│   ├── sync.js                  # [8] Firebase 클라우드 동기화 및 모바일 전용 로그인 폼
│   └── app.js                   # [9] 앱 초기화, 탭 라우팅, 스크롤 위치 복원, 이벤트 리스너
└── android/                     # Capacitor 안드로이드 네이티브 프로젝트
    └── app/src/main/res/raw/    # alarm_bell.wav (네이티브 알람 소리 원본)
```

## 3. 핵심 문제 해결 히스토리 (Troubleshooting)

### ① 구글 간편 로그인 시 ChatGPT로 튕기던 문제
- **원인**: 안드로이드 웹뷰(APK) 환경에서는 브라우저 팝업(`signInWithPopup`)이 차단되어 `signInWithRedirect`로 넘어가는데, 안드로이드 OS가 외부 웹 링크를 기기의 기본 어시스턴트(ChatGPT)로 넘겨버림.
- **해결**: 모바일 환경(`isNativeApp()`)을 자동 감지하여 모바일에서는 외부 튕김이 일체 없는 **앱 전용 직접 이메일/비밀번호 로그인 및 회원가입 폼**을 표시하도록 개편. 비밀번호 재설정 메일 발송 기능도 추가.

### ② 백그라운드에서 알림 메시지만 뜨고 소리가 안 나던 문제
- **원인**: 안드로이드 8.0 이상에서 NotificationChannel의 중요도(`Importance`)가 낮거나 사운드가 지정되지 않은 기본 채널로 알림이 발송되어 시스템이 백그라운드 소리를 묵음 처리함.
- **해결**: 고음질 알람벨(`alarm_bell.wav`)을 네이티브 리소스(`res/raw/alarm_bell.wav`)에 배치하고, 최고 중요도(`importance: 5`, `IMPORTANCE_HIGH`, `vibration: true`, `sound: 'alarm_bell.wav'`)를 갖는 전용 채널(`diary_loud_alarm_v3`)을 생성하여 화면 꺼짐 상태에서도 소리와 진동이 100% 울리도록 조치.

### ③ 첨부한 노래(MP3)가 앱 재시작 후 기계음으로 바뀌던 문제
- **원인**: 음원 첨부 시 임시 상태만 변경되고 즉시 저장되지 않아 앱 종료 시 기본음으로 리셋되었으며, Web Audio API `decodeAudioData`로 긴 MP3를 디코딩할 때 웹뷰 메모리 부족으로 디코딩 실패가 발생하여 기계음으로 폴백됨.
- **해결**: 음원 첨부 즉시 `S.cfg.alarmSound = 'custom'`으로 영구 저장하고, Base64 Data URL을 스마트폰 하드웨어 엔진인 HTML5 `new Audio(...)`로 스트리밍 재생하도록 개선하여 앱을 껐다 켜도 등록한 노래가 영구히 재생됨.

### ④ 하루 일정 조절 알림 (데일리 루틴 알림) 신규 추가
- **내용**: [설정] 탭에 전용 카드를 신설하여 매일 정해진 시간(기본 08:30)에 사용자가 입력한 메시지로 알람이 울리고, [오늘 일정 보러가기 📝] 버튼을 누르면 즉시 [일정] 화면으로 이동하는 기능 구현 완료.

## 4. 안드로이드 APK 빌드 환경 및 절차

- **JDK 위치**: `E:\Project\diary\.jdk21\jdk-21.0.13+9` (Eclipse Temurin JDK 21 LTS 독립 설치본)
- **빌드 절차**:
  1. `node copy-www.js` (웹 자산을 `www/` 폴더로 동기화)
  2. `npx.cmd cap sync android` (Capacitor 네이티브 프로젝트에 반영)
  3. `android/gradlew.bat assembleDebug` (APK 컴파일)
  4. 컴파일된 APK를 루트의 `diary-debug.apk`로 복사
- **원클릭 빌드**: 프로젝트 루트의 `build-apk.bat` 실행 시 위 과정이 자동 수행됨.
