## 🌟 프로젝트 개요

- **타입**: 모바일 & 데스크톱 반응형 싱글 페이지 웹 애플리케이션 (SPA / PWA)
- **개발 환경/스택**: 순수 HTML5, CSS3, Modern Vanilla JavaScript (외부 프레임워크 종속성 없음)
- **주요 연동 Web API**:
  - **PWA Service Worker**: 오프라인 캐싱, 백그라운드 푸시/진동 알림, 앱 바로가기
  - **Web Audio API**: 4종 내장 합성 사운드 및 마스터 게인(Master Gain) 실시간 음량 제어
  - **IndexedDB**: 대용량 커스텀 글꼴(TTF/OTF) 및 사용자 MP3 음원 로컬 보관
  - **Web Notification & TimestampTrigger**: 시스템 레벨 알림 및 미래 시점 알람 사전 예약
  - **Web Crypto (SubtleCrypto)**: 일기 보안 잠금용 SHA-256 비밀번호 해시 암호화
  - **Canvas API**: 첨부 사진의 모바일 친화적 자동 리사이징 및 압축 저장
  - **Open-Meteo API**: 실시간 날씨 및 일기예보 연동
  - **Firebase SDK (Compat 10.12.2)**: Google 간편 로그인 및 Firestore 월별 분할 클라우드 백업

## 🏗️ 핵심 기술 아키텍처

### 1. 로컬 데이터 구조 (`localStorage: diary.v1`)
애플리케이션의 모든 주요 데이터는 `S` 객체에 보관되며, 변경 시마다 `save()`를 통해 로컬스토리지 및 Firebase 클라우드로 동기화됩니다.

```javascript
let S = {
  items: [],        // 개별 일정 목록 [{ id, date, title, time, alarm, done, detail }]
  reps: [],         // 반복 일정 목록 [{ id, title, time, alarm, kind, days, every, start, detail }]
  rdone: {},        // 특정 날짜의 반복 일정 완료 체크 플래그 { "YYYY-MM-DD|repId": 1 }
  skip: {},         // 특정 날짜에 건너뛴(삭제한) 반복 일정 플래그
  moods: {},        // 날짜별 기분 이모지 { "YYYY-MM-DD": "😀" }
  goalsM: {},       // 월별 목표 리스트 { "YYYY-MM": [{ id, t, done, doneOn }] }
  diary: {},        // 하루 일기 본문 및 첨부사진 { "YYYY-MM-DD": { title, text, photos: [] } }
  cfg: {
    lock: true,             // 일기 비밀번호 잠금 여부
    pw: "",                 // SHA-256 해시 비밀번호
    alarmSound: "chime",    // 선택된 알람 음원 (chime, beep, bell, marimba, custom)
    alarmVol: 80,           // 알람 음량 (0 ~ 100%)
    customAudioName: "",    // 첨부된 사용자 커스텀 MP3 파일명
    fontName: "",           // 적용된 커스텀 폰트명
    fs: 15,                 // 전체 글자 기본 크기 (px)
    grad: false,            // 배경 그라데이션 활성화 여부
    bg: [250, 248, 244],    // 기본 배경 RGB
    bg2: [236, 232, 224],   // 그라데이션 끝 배경 RGB
    tx: [43, 42, 39]        // 텍스트 글자색 RGB
  },
  fmt12: false      // 시간 표기 방식 (false: 24시간제, true: 12시간제 오전/오후)
};
```

## 📱 주요 4대 탭 기능 명세

### 1. [일정] 탭
- **1주일 캘린더 네비게이션**: 오늘, 이전 주, 다음 주 이동 및 요일별 공휴일/일정 점(Dot) 표기
- **일정 리스트**: 시간순 자동 정렬, 완료 체크, 삭제 시 5초 되돌리기(Undo) 토스트 지원
- **반복 일정 접기/펼치기**: 주기(요일별/며칠 간격)에 맞게 오늘 일정에 자동 노출, 알람 `⏰` 표기
- **하단 빠른 입력줄**: 텍스트 입력 후 시간 설정 시트 연동 및 Enter 키 즉시 추가

### 2. [달력] 탭
- **한 달 캘린더 그리드**: 공휴일(빨간색), 토요일(파란색), 오늘 표시
- **기분 이모지**: 5단계 감정(😀, 🙂, 😐, 😟, 😢)을 날짜별로 기록
- **월별 목표 관리**: 목표 달성 시 달력 날짜에 🚩 깃발 표시, 달성 통계 제공
- **날짜 상세 모달**: 달력의 특정 날짜를 터치하면 해당일의 모든 일정 및 메모 확인/추가 가능

### 3. [기록] 탭
- **비밀번호 보안 잠금**: SHA-256 해시를 이용한 다이어리 프라이버시 보호 (앱 이탈 시 자동 재잠금)
- **하루 일기 작성**: 제목 및 장문의 일기 작성, 실시간 자동 저장
- **사진 첨부**: 이미지 업로드 시 모바일 캔버스(Canvas)를 통해 최대 800px로 자동 압축 후 저장 (용량 최적화)

### 4. [설정] 탭
- **프로필 설정**: 다이어리 상단에 표출될 사용자 이름 지정
- **계정 & 백업**: Firebase Firestore 연동을 통한 월별/사진 분할 동기화 (화면 튐 방지 및 쿨다운 적용)
- **테마 & 색상**: 시그니처 6종 감성 그라데이션 프리셋, RGB 슬라이더 및 팔레트 실시간 미리보기 & 최종 저장
- **알람 및 사운드**: 알람 음원 선택, 실시간 음량 조절(0~100%), 내 MP3 음원 등록, [알람 소리 저장] 바
- **글꼴 & 화면**: 커스텀 폰트(TTF/OTF/WOFF) 업로드, 글자 크기(12~22px), 12/24시간 표기 토글

## 🛠️ 최근 작업 및 개선 히스토리 (Changelog)

### 1. 반복 일정 알람 기능 추가
- **문제점**: 기존에는 일반 일정만 알람이 울리고, 반복 일정(`reps`)에는 알람 설정 및 감시 루프가 누락되어 있었음.
- **해결 내역**:
  - 반복 일정 생성/수정 창(`drawRep`)에 `알람 없음`, `정시`, `10분 전`, `30분 전` 선택 드롭다운 추가
  - 반복 일정 목록 및 캘린더에 `⏰` 알람 아이콘 표출
  - `checkAlarms()` 감시 루프를 확장하여, 오늘 주기에 해당하는 반복 일정(`repOn`) 중 오늘 아직 완료(`rdone`)하지 않았거나 건너뛰지(`skip`) 않은 항목을 매 3초마다 순회 검사하여 알람 발송
  - 반복 일정 틀을 눌러 개별 일정으로 등록할 때(`A.tpl`)도 알람 옵션이 자동으로 인계되도록 연동

### 2. 백그라운드 및 앱 꺼짐 상태 알람 개선 (PWA & Service Worker)
- **문제점**: 모바일 브라우저의 전력 관리 정책으로 인해 브라우저 창이 닫히거나 화면이 꺼지면 자바스크립트 타이머가 정지되어 알람이 울리지 않음.
- **해결 내역**:
  - **`sw.js` (서비스 워커) 신규 구축 및 등록**: 브라우저 창이 닫혀도 시스템 백그라운드에서 동작할 수 있도록 PWA 인프라 구축
  - **시스템 레벨 사전 스케줄링 (`TimestampTrigger`)**: Chromium 계열(안드로이드 Chrome 등) 지원 환경에서 일정이 저장될 때 시스템 알람 스케줄러에 미래 알림을 미리 등록하여, **앱이 닫혀도 정해진 시간에 시스템 알림**이 발송되도록 구현
  - **강력 진동 및 지속 알림**: `vibrate: [500, 200, 500, 200, 500]` 및 `requireInteraction: true`를 적용하여 사용자가 확인하기 전까지 화면에 알림 유지
  - **화면 복귀/재개 시 즉각 알람 동기화**: `visibilitychange`, `focus`, `pageshow` 이벤트 리스너를 통해 기기 화면이 켜지는 순간 놓친 알람을 즉시 검사하여 발생
  - **백그라운드 알람 진단 도구**: [설정] 탭 내 **[⚡ 5초 뒤 백그라운드 알람 테스트하기]** 버튼을 탑재하여 사용자가 직접 화면을 끄고 진동/알림을 5초 뒤 즉시 검증할 수 있도록 지원

### 3. 알람 음원 선택 및 [알람 소리 저장] 전용 버튼 추가
- **문제점**: 음원 선택 드롭다운을 건드릴 때마다 즉시 저장되어 사용자가 원하는 소리를 테스트하고 확정하기 불편함.
- **해결 내역**:
  - 임시 선택 상태(`TEMP_SND`, `TEMP_VOL`)를 관리하여, 소리를 선택하고 테스트한 뒤 하단의 **[알람 소리 저장]**을 눌러야 영구 적용되도록 UX 개선
  - 저장 전에는 `🎵 소리가 변경되었어요 (저장 필요)` 문구 및 [취소] 버튼 제공

### 4. 실시간 음량 조절(0~100%) 및 소리 중첩(겹침) 완전 해결
- **문제점**:
  - 음량 슬라이더를 움직이거나 미리듣기를 누를 때마다 새로운 오디오 인스턴스가 계속 생성되어 소리가 서로 겹치며 들리는 현상 발생
  - 슬라이더를 조절할 때 노래가 끊기지 않고 자연스럽게 볼륨만 오르내려야 하는 요구사항 존재
- **해결 내역**:
  - **단일 오디오 인스턴스 컨트롤러(`stopAlarmSound`)**: 새로운 소리를 재생하거나 미리듣기를 누를 때 기존에 실행 중이던 모든 오실레이터, 커스텀 버퍼 소스, `AudioContext`를 즉시 강제 종료하여 **다중 음원 중첩을 원천 차단**
  - **Web Audio 마스터 게인(`MasterGainNode`) 연동**:
    - 내장 사운드 4종 및 커스텀 MP3가 모두 하나의 마스터 게인 노드를 통과하도록 설계
    - 음악이 재생 중일 때 볼륨 슬라이더를 드래그하면, **노래를 처음부터 다시 시작하지 않고 현재 재생 중인 노래의 볼륨(`activeMasterGain`)이 실시간으로 부드럽게 조절**
  - **미리듣기 토글 UI**: 소리가 재생 중일 때는 버튼이 **[⏹️ 재생 정지]**로 전환되어 언제든 터치하여 멈출 수 있음
  - **알람 팝업 [확인] 연동**: 실제 알람이 울려 팝업 모달이 떴을 때도 [확인]을 누르면 `stopAlarmSound()`가 호출되어 긴 MP3 음악도 즉시 종료

### 5. 웹 전용 스마트 무음 백그라운드 킵얼라이브 (Keep-Alive) 탑재
- **문제점**: 순수 웹앱 상태에서 스마트폰 화면이 꺼지거나 다른 앱으로 이동하면 OS가 브라우저를 절전 모드로 동결시켜 정시에 알람이 울리지 못함.
- **해결 내역**:
  - **스마트 절전 무음 오디오 세션**: 알람이 설정되어 있을 때만 화면 꺼짐(`visibilitychange: hidden`) 감지 시 48바이트 경량 무음 WAV 오디오 루프를 미세하게 가동하여, OS가 브라우저 탭을 잠재우지 못하도록 유지
  - **알람 없을 시 완전 절전**: 당일/익일 남은 알람이 없거나 이미 완료된 경우 무음 루프를 자동 정지하여 배터리 소모 방지
  - **[설정] 탭 토글 스위치**: `화면 꺼짐 시 알람 유지 (백그라운드)` 옵션을 제공하여 사용자가 원할 때 언제든 켜고 끌 수 있도록 지원
  - **5초 뒤 테스트 안정화**: 5초 뒤 알람 테스트 시 무음 오디오를 즉각 가동하여 버튼을 누르고 바로 화면을 꺼도 100% 정시에 진동/알람이 울리도록 보장

### 6. 기능별 파일 모듈화 분할 (HTML, CSS, JS 분리)
- **문제점**: `index.html` 단일 파일 크기가 93KB(1,314줄)로 방대해져, 사소한 수정 작업 시에도 모든 코드를 다시 읽고 써야 하므로 토큰 소모가 극심하고 작업 속도가 저하됨.
- **해결 내역**:
  - `index.html`을 30줄의 진입점 스켈레톤으로 축소
  - 스타일시트를 `css/style.css`로 분리
  - 자바스크립트를 역할별 9대 모듈(`js/state.js`, `js/audio.js`, `js/alarm.js`, `js/today.js`, `js/calendar.js`, `js/diary.js`, `js/settings.js`, `js/sync.js`, `js/app.js`)로 완벽 분리
  - `sw.js` 오프라인 캐시 목록을 v2로 갱신하여 오프라인 동작 보장
  - **작업 시 토큰 소모 90% 이상 절감 및 수정 속도 대폭 향상 달성**

### 7. 안드로이드 정식 APK 패키징 및 시스템 Exact Alarm (`AlarmManager`) 연동
- **문제점**: 웹 브라우저 기반 PWA는 사용자가 최근 실행 앱 목록에서 앱을 완전히 닫거나 스마트폰이 깊은 절전 모드에 들어가면 OS에 의해 브라우저 프로세스가 강제 종료되어 알람이 울리지 못함.
- **해결 내역**:
  - **Capacitor 8 네이티브 엔진 도입**: 웹 애플리케이션을 안드로이드 네이티브 APK로 패키징
  - **안드로이드 하드웨어 커널 권한 탑재**: `SCHEDULE_EXACT_ALARM`, `USE_EXACT_ALARM`, `WAKE_LOCK`, `RECEIVE_BOOT_COMPLETED`, `VIBRATE` 권한 등록
  - **하이브리드 스마트 스케줄러 (`syncNativeAlarms`)**:
    - 웹 브라우저에서 실행 시: 기존 PWA 서비스 워커 및 Web Audio 알람 동작
    - 스마트폰 앱(APK)에서 실행 시: 안드로이드 OS의 **`AlarmManager` 시스템 알람**으로 자동 전환되어 **앱이 완전히 꺼져 있거나 폰 화면이 꺼진 지 수 시간이 지나도 100% 정시에 화면을 깨우고 알람을 울림**
  - **`build-apk.bat` 원클릭 자동 빌드 스크립트 제공**: 더블 클릭 한 번으로 최신 코드를 반영하여 `diary-debug.apk`를 자동 생성

## 🤖 안드로이드 APK 설치 가이드 (앱이 꺼져도 100% 울리는 진짜 알람)

스마트폰에서 앱이 완전히 꺼져 있어도 알람이 울리게 하려면 생성된 APK 파일을 설치합니다:

1. **APK 파일 준비**:
   - 프로젝트 루트 디렉터리에 생성된 **`diary-debug.apk`** 파일(약 4.7MB)을 확인합니다.
2. **스마트폰으로 파일 전송**:
   - PC와 스마트폰을 USB 케이블로 연결하여 '다운로드(Download)' 폴더로 복사하거나,
   - 카카오톡 [나에게 보내기], Google Drive, 이메일 첨부 파일 등으로 전송합니다.
3. **스마트폰에서 설치**:
   - 스마트폰 파일 관리자(내 파일)에서 `diary-debug.apk`를 터치합니다.
   - *"보안상의 이유로 이 출처의 알 수 없는 앱을 설치할 수 없습니다"*라는 메시지가 뜨면, **[설정]**으로 이동하여 **[이 출처의 앱 허용]**을 켜고 설치를 완료합니다.
4. **권한 허용**:
   - 앱을 처음 실행할 때 알림 권한 허용 팝업이 뜨면 **[허용]**을 누릅니다.
   - 이제 알람을 맞춘 뒤 **앱을 최근 앱 목록에서 쓸어 올려 완전히 꺼두어도 정해진 시각에 안드로이드 OS가 폰을 깨우고 알람이 정상적으로 울립니다!**

## 📲 모바일 PWA 설치 & 백그라운드 알람 가이드 (APK 미설치 시)

모바일 기기(Android / iOS)에서 알람이 100% 확실하게 울리게 하기 위해 아래 설정을 권장합니다:

1. **홈 화면에 앱 설치 (PWA)**:
   - 스마트폰 브라우저(Chrome, 삼성 인터넷, Safari 등)에서 접속 후 메뉴(우측 상단 `⋮` 또는 공유 버튼)를 누릅니다.
   - **[홈 화면에 추가]** 또는 **[앱 설치]**를 선택하여 설치합니다.
   - 일반 브라우저 탭이 아닌 독립 애플리케이션으로 동작하여 백그라운드 유지력이 대폭 향상됩니다.

2. **배터리 최적화 예외 설정 (Android)**:
   - 스마트폰 [설정] > [애플리케이션] > **[다이어리]**(또는 브라우저) 선택
   - [배터리] 항목을 **'최적화'**에서 **'제한 없음'**으로 변경합니다.
   - 스마트폰 화면이 꺼지거나 깊은 절전 모드(Doze)에 진입해도 알람이 정상적으로 동작합니다.

3. **백그라운드 알람 자가 진단**:
   - 앱 내 **[설정]** 탭 > **[🔔 알람 및 사운드]** > **[📱 꺼진 상태 / 백그라운드 알람 가이드]** 메뉴를 엽니다.
   - **[⚡ 5초 뒤 백그라운드 알람 테스트하기]** 버튼을 누른 후, 즉시 스마트폰 화면을 끄고 5초 뒤 진동과 알림이 정상적으로 수신되는지 확인합니다.
